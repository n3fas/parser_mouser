# Парсер mouser.com

Универсальный парсер для поиска электронных компонентов на сайтах **Mouser** по их парт-номеру (поддерживает поиск как по **Mouser PN**, так и по **Manufacturer PN**) через официальный API Mouser. Программа предоставляет интерфейс командной строки (CLI), интерактивное консольное меню, а также многофункционального Telegram-бота.

## Особенности

- **Возможности поиска**: Ищет по **Mouser Part Number** или **Manufacturer Part Number** (с использованием резервного поиска по ключевым словам).
- **Различные интерфейсы**:
  - **CLI (`mouser_cli.py`)**: Выполнение команд с передачей аргументов.
  - **Интерактивное меню (`mouser_menu.py`)**: Консольное меню для выполнения запросов и работы с файлами.
  - **Telegram-бот (`telegram_bot.py`)**: Отправляйте парт-номера текстом или прикрепляйте список в Excel `.xlsx`, чтобы получить форматированные результаты прямо в чате.
- **Богатый сбор данных**: Собирает данные о Mouser PN, Manufacturer PN, Производителе, Категории (EN), Описании, Ссылке на фото, Ссылке на даташит и информации о Compliance (соответствии нормам).
- **Автоматический перевод**: Автоматически переводит Категории и Описания компонентов с английского на русский с помощью Google Переводчика.
- **Массовая обработка данных (через Excel)**: Загрузите Excel файл со столбцом `Part no.` (или подобным), и парсер автоматически соберет данные по всем деталям из списка и вернет вам полностью заполненный `.xlsx` файл.
- **Локальная база данных (Кэш в `SQLite`)**:
  - Предотвращает дублирование запросов, кэшируя ответы от API локально, тем самым экономя лимиты Mouser API.
  - Отслеживает и сохраняет историю поисков пользователей.
- **Умная подсветка в Excel**:
  - Подсвечивает строки в зависимости от специфики категории:
    - 🟨 **Бледно-желтый**: Категории, требующие обязательных разрешительных документов.
    - 🟥 **Светло-красный**: Категории товаров, подлежащих обязательной маркировке.
    - 🟦 **Светло-синий**: Продукты, требующие и наличия документов, и маркировки.
  - Выделяет ячейки на основе реестра интеллектуальной собственности (ТРОИС):
    - 🟪 **Фиолетовый жирный шрифт**: Бренды, входящие в загруженный локальный реестр ТРОИС.
- **Ротация API ключей (обход Rate Limiting)**: Поддерживает одновременно несколько API-ключей (заданных как `MOUSER_API_KEY`, `MOUSER_API_KEYS`, `MOUSER_API_KEY_1` и т.д.), распределяя между ними нагрузку для избежания ошибок 429.

## Установка

### 1. Создайте и активируйте виртуальное окружение
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate
```

### 2. Установите зависимости
```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Скопируйте конфигурационный файл из шаблона:
```bash
cp .env.example .env
```
Откройте файл `.env` и добавьте свои настройки:
- `MOUSER_API_KEYS` (или один ключ `MOUSER_API_KEY`)
- `TELEGRAM_BOT_TOKEN`, `ADMIN_USER_ID`, `ALLOWED_THREAD_ID` (если планируете использовать Telegram-бота)

## Использование

### Интерактивное меню
Запустите интерактивное консольное меню:
```bash
python mouser_menu.py
```
Следуйте подсказкам на экране для ввода одного или нескольких парт-номеров, просмотра результатов в виде таблицы или экспорта данных в CSV, JSON, XLSX.

### Интерфейс командной строки (CLI)
Скрипт также можно использовать для вывода данных напрямую в консоль или других автоматизированных скриптов:
```bash
python mouser_cli.py MAX3232 579-24LC02B-I/SN --format xlsx --out report.xlsx
```
Используйте флаг `python mouser_cli.py -h`, чтобы увидеть полный список доступных аргументов.

### Telegram-бот
Запустите фоновый скрипт для обработки Telegram-запросов:
```bash
python telegram_bot.py
```
Пользователи могут отправлять парт-номера просто сообщением или как вложение файла `.xlsx`. 
Встроенная команда `/menu` предоставляет доступ к инлайн-меню для управления историей поиска, статистике базы данных, спискам пользователей (доступно только Админу), записям реестра ТРОИС и категориям для выделения в таблицах.
